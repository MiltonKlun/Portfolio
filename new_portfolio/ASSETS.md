## Ambient motion and hover effects

React Bits Ghost Fibers is loaded on the landing gallery as a faint overlay over the existing image set: two layers, 24 fps, render scale 0.65, no grain. The module and OGL are loaded separately after initial rendering. Reduced motion avoids creating the canvas; hidden tabs, offscreen rendering and open navigation pause it. Context loss falls back to the original artwork. Only one canvas exists across the five chapters.

The theme button uses an adapted React Bits Border Glow conic mask and layered edge shadows. Menu links adapt the Shiny Text gradient into one CSS sweep on hover or focus, without continuous text animation or a Motion dependency. Original component references are https://reactbits.dev/components/border-glow, https://reactbits.dev/text-animations/shiny-text, and https://reactbits.dev/backgrounds/ghost-fibers. Upstream license is included in THIRD_PARTY_NOTICES.txt.
